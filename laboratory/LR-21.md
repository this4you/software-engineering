# Лабораторна робота: API та інтеграції

## Мета

Закріпити теорію з лекції на практиці. Ти запускаєш реальний API-сервіс,
викликаєш його різними способами (REST, GraphQL, WebSocket, Kafka), і
оформлюєш короткий звіт з тим, що бачив(ла).

## Передумови

- Проект склонований і запущений (`./gradlew bootRun`) — інструкція в
  [README.md](https://github.com/this4you/api-example/blob/main/README.md).
- Пройдено хоча б першу Практику з README — ти бачив(ла) Swagger UI.
- Для завдання 8 (Kafka) додатково потрібен Docker — `docker compose up -d`.

> Якщо щось не запускається — спочатку переглянь розділ "Поради" в кінці
> цього файлу, потім питай викладача.

## Як здавати

- **Формат:** один файл `lab_api_<прізвище>.md` або PDF.
- **Структура файлу:**
    1. Титулка (ПІБ, група, дата).
    2. По одному розділу на кожне з 8 обов'язкових завдань.
    3. (Опціонально) розділи з бонусними завданнями.
    4. Розділ "Відповіді на питання".
    5. Чек-лист самоперевірки.
- **Скріни** — вставляти прямо в MD синтаксисом `![підпис](шлях/до/файлу.png)`.
  Для PDF — просто вставити в Word і експортувати.
- **Здача:** як домовлено з викладачем (Google Classroom / пошта / Moodle).

## Завдання 2 — Аутентифікація через JWT

**Практика в README:** [Практика 3 — Аутентифікація через JWT](https://github.com/this4you/api-example/blob/main/README.md#практика-3--аутентифікація-через-jwt)

**Що зробити:**
1. Викликати `POST /auth/login` з кредами `admin / admin`, скопіювати токен.
2. Виконати `GET /api/v1/books` без токена → отримати 401.
3. Виконати той самий запит з токеном → отримати 200 і список книг.

**Що включити у звіт:**
- Скрін терміналу з відповіддю від `/auth/login` (з токеном).
- Скрін 401 без токена.
- Скрін успішного запиту з токеном (видно список книг).
- Скрін 401 з зіпсованим токеном.

**Самоперевірка:** усі 4 скріни є; статуси відповідей правильні.

## Завдання 3 — REST CRUD

**Практика в README:** [Практика 4 — REST CRUD](https://github.com/this4you/api-example/blob/main/README.md#практика-4--rest-crud-create-read-update-delete)

**Що зробити:**
1. Створити нову книгу через `POST /api/v1/books` (придумай свою — назву,
   автора, ISBN з 13 цифр).
2. Отримати її через `GET /api/v1/books/{id}`.
3. Видалити через `DELETE /api/v1/books/{id}`.

**Що включити у звіт:**
- Скрін `POST` з видимим статусом **201 Created** і заголовком **Location**.
- Скрін `GET` з даними створеної книги.
- Скрін `DELETE` зі статусом **204 No Content**.
- 1 речення: чому DELETE повертає 204, а POST — 201?

**Самоперевірка:** на трьох скрінах видно різні статус-коди (201, 200, 204).

# Частина 3 — Відповіді на питання

Напиши коротку відповідь (1-3 речення) на кожне:

1. **(Завдання 1)** Уяви фронтенд-розробника, який інтегрується з нашим API,
   але не має Swagger. Які три типи помилок він з найбільшою ймовірністю
   зробить?

2. **(Завдання 2)** Що станеться, якщо токен JWT перехопити в публічному
   Wi-Fi? Що зазвичай роблять, щоб це не було катастрофою?

3. **(Завдання 3)** Чому в REST не варто робити URL виду `/getBooks` або
   `/deleteBook/5`?

4. **(Завдання 4)** Користувач каже: "у мене не пройшла оплата вчора десь
   увечері". У тебе мільйони рядків логів за день. Як traceId допомагає?

5. **(Завдання 5)** Ти додаєш у JSON-відповідь нове поле `discount`. Це
   breaking change? А якщо перейменовуєш `priceUah` на `price`?

6. **(Завдання 6)** Чому GraphQL зручніший для мобільних застосунків зі
   слабким інтернетом?

7. **(Завдання 7)** Telegram надсилає тобі повідомлення миттєво. Як це
   реалізовано — твій телефон опитує сервер кожну секунду, чи Telegram
   надсилає сам?

8. **(Завдання 8)** Який сценарій кращий для оплати замовлення: (а) фронтенд
   30 секунд чекає, поки банк підтвердить, чи (б) бекенд приймає замовлення,
   повертає 202 Accepted і обробляє асинхронно через чергу? Чому?

# Поради

**Скріни:**
- macOS: `Cmd + Shift + 4` (виділена область) або `Cmd + Shift + 5` (меню).
- Windows: `Win + Shift + S` (інструмент "Знімок екрана").
- Linux (GNOME): `Shift + PrintScreen`.

**Вставка картинки в MD:**
```markdown
![Swagger UI зі схемою BookRequestV1](images/task1-swagger.png)
```
Папка `images/` має лежати поруч із твоїм `.md` файлом.

**Що робити, якщо щось не працює:**
1. Перевір, чи Spring Boot ще запущений (`./gradlew bootRun`).
2. Подивись у логи в терміналі — там є причина.
3. Для Завдання 8 — переконайся, що Docker запустив контейнери:
   `docker ps` має показати `api-example-kafka` і `api-example-kafka-ui`.
4. Якщо JWT-токен застарів (за замовчуванням живе 60 хв) — отримай новий.
5. Якщо нічого не допомогло — питай викладача, прикріпивши скрін помилки і
   логи.
