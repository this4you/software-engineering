## Завдання 6 — Команда для викладача ⭐

**Як підняти мій проект (одна команда):**

```bash
docker run -d -p 8080:8080 <твій_dockerhub_логін>/coursework:1.0
```

- Образ на Docker Hub: `https://hub.docker.com/r/<логін>/coursework`
- (або) Репозиторій з Dockerfile: `<посилання>`

![docker push](images/push.png)

> Я перевірив(ла) цю команду «з чистого аркуша» (видалив локальний образ і
> підняв заново): так / ні.
